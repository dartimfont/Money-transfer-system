# Мини-система денежных переводов на Go

### Система денежных переводов между пользователями на структурах, методах, интерфейсах и горутинах.

Тонкости задачи
Задание из 4 частей, каждая дополняет предыдущую.

### Каждая версия сохраняется по веткам:

- **v1** - Часть 1: Основы – создание пользователей и выполнение простых транзакций
- **v2** - Часть 2: Добавление транзакций и обработка нескольких пользователей
- **v3** - Часть 3: Введение в конкурентность — обработка транзакций с горутинами
- **v4** - Часть 4: Реализация конкурентного доступа

## Запуск программы

Выбрать нужную версисю программу через
```cmd
git switch v1[v2, v3, v4]
```

Перейти в папку с проектом, выполнить команду в консоли
```cmd
go run main.go
```
